# AICTE OIB-SIP Internship – Task 5
## Sales Prediction using Python

## Domain
Data Science

## Objective
The objective of this project is to predict future sales based on historical data using machine learning techniques in Python.

## Dataset
A sales dataset containing features such as advertising expenditure, sales amount, or other related variables is used for prediction.

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / VS Code

## Project Workflow
1. Loaded the sales dataset
2. Performed data preprocessing and cleaning
3. Conducted exploratory data analysis (EDA)
4. Visualized relationships between features and sales
5. Built a regression model to predict sales
6. Evaluated model performance using metrics like R² score and Mean Squared Error

## Outcome
Successfully developed a sales prediction model that can estimate sales based on input features using Python.
